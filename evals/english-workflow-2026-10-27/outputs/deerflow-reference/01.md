## Summary

QuantCache investigates whether quantized feature caching improves batch-one sensor classification latency on three datasets. The matched measurements support a practical speed benefit, but the evaluation does not establish the claimed bound on expected unseen-subject F1.

## Strengths

1. Section 3 separates caching from quantization through matched configurations, helping attribute the latency reductions to each change.
2. Timing includes preprocessing and cache lookup on the same CPU. The reduction from 12.4 to 5.1 ms is practically meaningful, with the additional 28 MB memory cost disclosed.
3. Sections 2–4 describe subject separation, training-only feature construction, shared seeds, and the narrow application scope clearly.

## Weaknesses

1. Section 2 maximizes each method's F1 threshold using the full test labels and evaluates it on those same labels. The decision rule therefore uses held-out outcomes; this procedure does not estimate the performance of a fully frozen pipeline on unseen subjects. Select thresholds on validation subjects, freeze them, and evaluate once on untouched test subjects.
2. Section 4's “at most .003” expected-performance bound exceeds the evidence. Small differences between reported means, together with training-seed standard deviations, do not bound uncertainty over new subjects. After correcting threshold selection, report uncertainty for paired performance differences with subject-level sampling respected, or limit the conclusion to the observed differences.

## Overall Assessment

Major revision. The latency evidence and controlled comparisons are valuable within the stated scope, but the accuracy evaluation and expected-performance claim require correction before the joint speed–accuracy conclusion is supported.
